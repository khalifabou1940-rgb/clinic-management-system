# 🏥 نظام إدارة العيادة الطبية
# Clinic Management System

## نظام متخصص وشامل لإدارة العيادات الطبية

برنامج سطح المكتب الاحترافي المصمم خصيصاً لمساعدة الأطباء والعاملين الصحيين على إدارة عيادتهم بكفاءة وسهولة.

---

## ✨ المميزات الرئيسية

### 👥 إدارة المرضى
- إضافة وحفظ بيانات المرضى بالتفصيل
- دعم اللغة العربية والفرنسية
- تسجيل السجل الطبي والحساسيات
- البحث السريع عن المرضى

### 📅 جدولة المواعيد
- حجز المواعيد الطبية بسهولة
- عرض مواعيد اليوم والجدول الزمني
- تأكيد أو إلغاء المواعيد
- إدارة حالة الموعد (في الانتظار، مؤكد، مكتمل، ملغى)

### 💊 إدارة الوصفات الطبية
- إنشاء وصفات طبية لكل مريض
- تسجيل الدواء والجرعة والتكرار والمدة
- طباعة الوصفات في ملفات PDF احترافية
- إضافة تعليمات وملاحظات للدواء

### 📋 السجلات الطبية
- تسجيل الزيارات الطبية
- توثيق الأعراض والتشخيص والعلاج
- حفظ تاريخ طبي شامل لكل مريض
- إمكانية طباعة التقارير الطبية

### 🔔 نظام التذكيرات
- تذكيرات تلقائية للمواعيد
- إرسال تنبيهات قبل موعد الزيارة بيوم
- دعم اللغة العربية والفرنسية
- سجل كامل للتذكيرات المرسلة

### 💾 النسخ الاحتياطية
- نسخ احتياطية تلقائية للبيانات
- استعادة البيانات من أي نسخة احتياطية
- حماية البيانات من فقدان الأهمية

### 🖥️ واجهة استخدام حديثة
- تصميم احترافي وسهل الاستخدام
- دعم كامل للغة العربية والفرنسية
- لوحة تحكم توضح الإحصائيات المهمة
- اختصارات سريعة وأزرار واضحة

---

## 🛠️ المتطلبات

- Python 3.8 أو أحدث
- نظام تشغيل: Windows, macOS, أو Linux
- لا يتطلب اتصال بالإنترنت (يعمل محلياً بالكامل)

## 📦 التثبيت والتشغيل

### 1. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

### 2. تشغيل البرنامج

```bash
python main.py
```

## 🎯 طريقة الاستخدام

### إضافة مريض جديد
1. انقر على تبويب "المرضى"
2. اضغط على زر "إضافة مريض جديد"
3. املأ البيانات المطلوبة
4. اضغط "حفظ"

### حجز موعد
1. انقر على تبويب "المواعيد"
2. اضغط على "حجز موعد جديد"
3. اختر المريض والتاريخ والوقت
4. أضف سبب الزيارة
5. اضغط "حفظ"

### إنشاء وصفة طبية
1. انقر على تبويب "الوصفات"
2. اضغط على "وصفة جديدة"
3. اختر المريض واملأ معلومات الدواء
4. اضغط "حفظ"
5. اختر الوصفة واضغط "طباعة" لطباعتها

### تسجيل زيارة طبية
1. انقر على تبويب "الزيارات"
2. اضغط على "زيارة جديدة"
3. اختر المريض ودون الأعراض والتشخيص والعلاج
4. اضغط "حفظ"

## 🔐 الأمان والخصوصية

- **لا توجد عمليات إرسال بيانات عبر الإنترنت**

- نسخ احتياطية تلقائية لحماية البيانات
- يمكنك استعادة البيانات في أي وقت
